# Support Information 🛠️ (HYDRA-UMC-UPDATER)

Thank you for using HYDRA-UMC-UPDATER! Here is how you can get help:

## 📺 Video Tutorials & Demos

The best way to see how this tool detects, installs, and updates the
HYDRA-UMC/URTC ecosystem is through our official YouTube channel:
[youtube.com/@electrohobby3d](https://youtube.com/@electrohobby3d)

## ✉️ Direct Technical Inquiries

For questions about running this on your own CM5, a custom deployment
layout, or anything not covered by the README:
Email: `electrohobby3d@gmail.com`

## 🐛 Bug Reports

If `hydra-umc-updater status` reports the wrong version for a project, or
`install`/`update` fails for a project whose own `build.sh`/`.bat` works
fine when run directly, please open a **GitHub Issue** in this repository
- include the exact command you ran and its full output.
*Please search existing issues before opening a new one.*

## ❌ What is NOT support?

- This tool does not build/install projects FOR you beyond running their
  own existing build script - a build failure inside a specific project's
  own `build.sh`/`.bat` is that project's own issue tracker, not this
  one's.
- Please do not use Issues for "how do I set up project X" questions -
  that belongs on project X's own README/Issues.
